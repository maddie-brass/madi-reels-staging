# madi-reels-staging

Temporary public hosting so Metricool can import videos by URL.

- `staging/<batch>/` holds files only until Metricool has copied them (scheduled posts point to static.metricool.com, not here).
- After a batch is scheduled, its files are removed in a follow-up commit.
- Future use: DJI camera footage pulled onto the MacBook can be staged here the same way.
